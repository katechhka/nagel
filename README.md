# NIKA NAGEL

Локальная вёрстка лендинга: адаптивная шапка и первый экран.

```sh
npm install
npm run dev
```

Проверка сборки: `npm run build`. Просмотр сборки: `npm run preview`.

Логотип: `images/n-monogram.svg`, из чата «Создать SVG-логотип с буквой N».
Шапка использует локальный Golos Text 400/500. Заголовки, включая Nika Nagel на первом экране, используют Cormorant Garamond Regular 400. Шрифт и лицензия SIL OFL находятся в src/fonts; правила — в DESIGN.md.

Под первым экраном расположена временная панель сравнения двух сгенерированных фотографий.
Изображения: `images/hero-portrait.png` и `images/hero-salon.png`; промпты — `images/hero-prompts.md`.
Проверка адаптива: `output/qa.html` (iframe 1440 и 390 px), не входит в сборку.
Ссылка «Услуги и цены» первого экрана пока ведёт на действующий сайт; после создания секции заменить на `#services`.

Онлайн-запись ведёт на `https://b2.beauty-saas.ru/27380a` — адрес из сохранённого исходника сайта.
Перед публикацией проверить актуальность сервиса записи.

Навигация подготовлена к секциям `#services`, `#masters`, `#quality`, `#salons`.
Сами секции пока не сверстаны, поэтому переходы по этим якорям заработают на следующих этапах.
Для проверки фиксации на пустой странице можно временно увеличить высоту main через DevTools.
