# Изображения с текущего сайта NIKA NAGEL

Источник: https://salon.nika-nagel.com/

Скачано 61 уникальных файлов. Оригинальные изображения Tilda сохранены без уменьшения; одинаковые файлы объединены по SHA-256. В набор входят фотографии, логотипы, иконки и декоративные изображения, указанные в HTML и подключённых CSS главной страницы.

- Файлы изображений находятся в этой папке.
- partners/ — логотипы партнёров (24 файлов).
- index.html — галерея для просмотра в браузере.
- manifest.json — исходные URL, размеры файлов, контрольные суммы и ошибки загрузки.
- source.html — исходный HTML страницы на момент скачивания.
- download.cjs — скрипт повторной загрузки (Node.js 22+).
