# Дизайн сайта NIKA NAGEL

## Анимация первого экрана

При первом появлении текстовой части в области просмотра элементы последовательно проявляются из прозрачности с подъёмом на 20px: описание сети, Nika Nagel, основной текст, каждая кнопка и затем каждый адрес. Длительность появления — 650ms, шаг — 120ms. Реализация — `src/js/hero-reveal.js`, Web Animations API и IntersectionObserver. Анимация однократная, не меняет геометрию страницы. При reduced motion, отсутствии JS или поддержки API текст виден сразу. При клавиатурном фокусе внутри блока все элементы сразу показываются.

## Проверка адаптива 3 ноября 2026

Проверены 23 ширины окна от 320 до 2560px, включая обе стороны основных брейкпоинтов. На узких телефонах плитки услуг располагаются в одну колонку; на планшете форма находится под картой, а карточки салонов и блоки качества переходят в одну колонку до того, как текст становится тесным. Общие размеры кнопок сохраняются.

До 480px описание первого экрана переносится естественно без принудительных desktop-break, портрет использует пропорцию 1.1 для более крупного кадра. Адрес не разрывается внутри строки. На планшете портрет в блоке качества не растягивается по высоте письма. Прокрутка к элементам формы учитывает фиксированную шапку.

Проверены мобильное меню и Escape, открытый прайс при 320×640 и 844×390, список салонов с клавиатурой, обе правовые страницы при 320/768/1440px. Переполнений страницы не обнаружено; отчёты и снимки — в `output/responsive-*` и `output/legal-responsive-audit.json`. Проверка выполнялась во встроенном Chromium, без проверки на физических устройствах. Отправка заявок в рамках проверки адаптива не выполнялась.

## Общий интервал между секциями

Адаптивная проверка 3 ноября 2026: главная проверена в браузере на ширинах 320, 360, 390, 430, 480, 600, 700, 701, 768, 820, 900, 1023, 1024, 1100, 1280, 1440, 1920 и 2560px. Кнопки первого экрана допускают перенос. Логотипы партнёров до 1023px переходят в четыре колонки, до 480px — в три, чтобы сохранять читаемый размер; свободная композиция остаётся на широком экране. Кнопка мобильного меню имеет область 44×44px. Проверены меню, прайс (включая альбомную ориентацию 844×390), список салонов и правовые страницы на 320/768/1440px. Отправка формы не выполнялась.

Все соседние секции главной страницы разделяются одним токеном `--section-gap` из `src/css/site.css`: 64px на широком экране, 48px до 1023px, 40px до 700px. Интервал задаётся через `.site-main > section + section`, а перед подвалом — через `.site-main + .site-footer`. Индивидуальные внешние вертикальные padding секций убраны, чтобы соседние отступы не складывались. Внутренняя композиция первого экрана, расстояния от заголовков до содержимого и интервалы внутри блоков сохраняются.

## Партнёры

Скорость общего появления в фотогалерее и блоке партнёров замедлена: длительность каждого элемента 1100ms, интервал между элементами видимой группы 180ms. Эти значения заменяют прежние 650/120ms; порядок остаётся случайным.

Анимация появления партнёров повторяет фотогалерею через общий `initWorksReveal`: случайный порядок видимых логотипов, длительность 650ms, интервал 120ms, плавное смещение снизу на 20px. Каждый логотип появляется один раз при прокрутке. Исходные адаптивные смещения сохраняются, увеличение при наведении остаётся на изображении. При reduced motion все логотипы видны сразу.

Текущее оформление заголовка: по последнему запросу пользователя «Наши партнёры» возвращён над логотипами, по центру, в обычном регистре и графитовом цвете. Cormorant Garamond 400, размер clamp(42px, 4.2vw, 64px), отступ снизу 32px (24px на мобильном). Фоновая надпись отменена.

Последнее уточнение: блок снова внутри общего `.container`, с его штатными шириной и боковыми отступами. Все 24 логотипа подключаются как PNG с настоящим альфа-каналом из `images/partners/transparent`; исходники сохранены. Белые и сплошные серые внешние подложки удалены программно по согласованию с пользователем, без перерисовки. У трёх белых знаков после удаления серой подложки применяется `brightness(.55)` для читаемости на светлом фоне. `mix-blend-mode` больше не используется. Круглые фирменные эмблемы сохраняют внутреннюю заливку и белые надписи; фон вокруг эмблем прозрачен.

Актуальное оформление заголовка по запросу пользователя: «Наши партнёры» крупными прописными буквами Cormorant Garamond 400 по центру позади логотипов, графит с opacity .08. Отдельного заголовка над композицией нет. Высота баннера уменьшена до clamp(330px, 52svh, 460px), мобильные вертикальные интервалы — 10px.

Блок `#partners` после `#regular-care`: все 24 исходных логотипа из `images/partners`, без обрезки. По уточнению пользователя логотипы образуют свободную баннерную композицию на всю ширину контейнера: разные размеры и нерегулярные смещения, без карточек, белых подложек и скруглений. Белый фон внутри исходных изображений сливается с фоном секции через `mix-blend-mode: multiply`. На широком экране шесть колонок, на мобильном четыре; компактная высота зависит от высоты экрана. Заголовок по центру, Cormorant Garamond 400, без дополнительных подписей. При наведении логотип плавно увеличивается до 1.045 за 400ms; при reduced motion переход отключён.

## Принципы применения

Основу оставлять светлой. Графит добавляет контраст, розовый связывает сайт с интерьером салонов. Розовый использовать дозированно: ориентир — около 10% площади страницы, без обязательного точного соотношения.

На розовых кнопках использовать графитовый текст `#242426`. На графитовых поверхностях использовать светлый текст `#F2F0ED`. Серый `#99928F` предназначен для деталей; для текста и значимых элементов интерфейса проверять контраст относительно фактического фона.

Не вводить яркий неоновый розовый вместо утверждённого акцента. Изменения основной палитры согласовывать с пользователем.

## Услуги и цены

Карточки услуг однократно появляются при входе в область просмотра: прозрачность 0→1 и смещение снизу 20→0px, 650ms, `cubic-bezier(.22, 1, .36, 1)`, интервал 120ms между одновременно видимыми карточками — как на первом экране. На телефоне следующие карточки ждут своей прокрутки. Без JS, при reduced motion и при переходе фокуса с клавиатуры карточки доступны сразу.

Фотографии карточек «Стрижки и окрашивание», «Уход за волосами» и «Брови» слегка приглушены через CSS `saturate(.65) contrast(.94) brightness(.97)`, чтобы приблизить их к спокойному тону маникюра. Фильтр применяется только к изображениям, подписи и стрелки сохраняют исходный цвет. Дополнительные плашки и подсказки о ценах не добавляются.

После первого экрана расположен `#services`: заголовок по центру без дополнительной строки и пять фотоплиток со скруглением 18px, на мобильном 14px. На широком экране три колонки; плитка «Стрижки и окрашивание» занимает две. На мобильном маникюр, стрижки и лицо/тело занимают всю ширину, уход за волосами и брови стоят рядом. Подписи плиток — Golos Text Regular 400, 24px на широком экране, 22px на планшете и 20px на мобильном; белая стрелка без круга направлена вправо и поворачивается на 45° вверх при наведении на плитку или клавиатурном фокусе. Фотографии взяты из локальной медиатеки.

Общий нативный `dialog` показывает соответствующий прайс: закреплённые заголовок и кнопка записи, прокручиваемое содержимое, закрытие по Escape, крестику и клику на подложке. Фокус возвращается на исходную плитку. Кнопка записи использует общие `.btn.btn1`; новые цвета и шрифты не вводятся.

Тексты взяты из «Тексты сайта NIKA NAGEL.md», цены — из сохранённого `images/source.html` от 27 октября 2026 года; данные находятся в `src/js/prices.js`. Неоднозначная дублирующая строка окрашивания за 250 ₽ и противоречивые цены дарсонваля/мезотерапии не перенесены. Цены необходимо сверить с салоном перед публикацией. Снятие покрытия не объявляется включённым для всех ногтевых услуг: область исходного примечания неоднозначна.
