# Контакты

Блок `#salons` в `index.html`: три адреса из текстов проекта, карта слева и форма справа; на мобильном — одна колонка. Цвета и шрифты наследуют токены `src/css/site.css`, оформление блока — `src/css/contacts.css`. Заголовки Cormorant Garamond 400, адреса и форма Golos Text 400. Кнопки используют общие `btn`, `btn1`, `btn2`, стрелки — `#icon-arrow`.

- `data-map-key` на `[data-partners-map]`: собственный ключ JavaScript API Яндекс Карт 2.1. Адреса, координаты и город хранятся в `data-map-points` и `data-map-cities`. Геокодер не используется: координаты трёх адресов сверены с опубликованной картой салона (3 ноября 2026). Формат API 2.1 — `[широта, долгота]`: Октябрьская, 74 — `[54.216041, 37.623474]`; Кирова, 143 — `[54.208938, 37.658877]`; Калинина, 10 — `[54.197457, 37.654089]`. Источник координат: https://yandex.ru/map-widget/v1/?um=constructor%3Aa548de9c3fbe965812d9e6091be6c2ccf83888aa06dca15fae7c258794f50c4a. Сам конструктор на сайте не подключается. Метки оформлены монограммой N. Без ключа показывается сообщение и доступны ссылки маршрутов. Подложка обесцвечивается отдельно от розовых меток, предложение открыть Яндекс Карты отключено через `suppressMapOpenBlock`. Модуль и карта загружаются при приближении блока на 300px.
- `data-endpoint` на `[data-contact-form]`: адрес POST-обработчика заявок. Поля: `name`, `phone`, `salon`, `message`, `consent`. Без обработчика форма показывает сообщение о недоступности и телефон, данные не отправляет. Подтверждение показывается только после успешного HTTP-ответа. Обработчик должен проверять данные и согласие на сервере.
- Согласие обязательно, изначально выключено. Документы подключены по `/privacy.html` и `/consent.html`, их содержание поддерживается отдельно.
- Выбор салона: `src/js/salon-select.js`, раскрываемый список шириной с поле, выбор мышью и клавиатурой (стрелки, Home/End, Enter, Escape). Нативный select сохраняет значение для FormData.
- Под блоком — компактные иконки и ссылки ВКонтакте, Telegram и Instagram из исходного сайта салона; повторная строка телефона и графика удалена.
- Кнопки записи ведут в существующий сервис Beauty SaaS; выбор конкретного филиала происходит там. Фотографии входов и ассортимент по филиалам не добавлены: подтверждённых соответствий в проекте нет.

Проверка: production-сборка Vite и `node --check` модулей. В браузере на `http://localhost:5173/#salons` проверены загрузка подложки, три метки N и завершение загрузки; ошибок консоли нет. Python-аудит недоступен: Python не установлен. Реальная доставка заявки требует подключения обработчика.
